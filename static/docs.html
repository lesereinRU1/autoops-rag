接口测试

本页按钮会直接请求当前电脑上的服务。返回内容来自正在使用的Qdrant索引和资料文件。本地检索不需要API Key。
项目页面接口结构和字段定义OpenAPI文件

手册查询

短追问会使用本页最近1到2轮问题，记录24小时有效。可随时点击清空本页会话。
点击按钮后会显示HTTP状态码、耗时和实际返回结果。

接口用途

接口用途
GET /health检查服务、索引数量和资料状态。
GET /api/index/status查看向量模型、Qdrant集合和切片数量。
POST /api/search返回相关手册片段，不生成答案。
POST /api/chat选择查询工具并生成带来源的回答。
GET /api/traces/{request_id}按请求编号查看单次检索和生成记录。
GET /api/traces/recent查看最近的检索和生成记录。
GET /api/alarms/{code}查询结构化故障码记录。
POST /api/feedback记录有帮助或无帮助。
POST /api/solutions/verify保存人工确认的处理方案。
DELETE /api/sessions/{session_id}清空指定会话的最近问题记录。
