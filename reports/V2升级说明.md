# AutoOps RAG V2 修改记录

> **Historical / stale / 历史版本材料。** 其中 corpus、测试和架构数字不是当前结果；当前事实见 `docs/current-status.md`。

## 已确认的问题

1. 原24题评测按预期关键词命中，只适合流水线冒烟，不是企业检索的gold评测。
2. 原系统虽有LangGraph路由和方案保存接口，但网页没有反馈入口，已验证方案也不会回流下一次回答。
3. 原系统没有领域关系图谱；故障码、指令、参数之间的关系只隐含在文本里。
4. 经典S7-1200语料使用V4.6，而官方已有V4.7；资料新鲜度必须显式披露。
5. 原PDF只按正文切片，表头与单元格值容易被拆散，无法证明带表格文档的检索能力。
6. 被中止的本地索引重建可能留下旧points，必须校验切片文件与向量库数量一致。

## 实际整改

- 新增2025版 S7-1200 G2 V1.0.1 中文官方手册，语料增加到1785页。
- 同时保存正文页和结构化表格行。表格处理包括严格线框检测、表头整理、表号、行号、边界框和URL版式过滤。最终生成16969个切片，其中12035个表格行覆盖1861张表。
- `sources.json` 增加发布日期、核验日期和状态；`check_sources.py`输出新鲜度报告，经典V4.6标明已被V4.7替代。
- 增加设备、协议、指令、故障码和参数之间的关系记录。故障码查询会使用这些关系，页面显示匹配结果和来源。
- 页面显示工具选择、关系查询、历史方案查询、混合检索、证据检查和回答生成记录。
- 页面增加有帮助、无帮助和保存已确认方案。相似问题可以使用已经保存的方案，同时重新查询手册证据。
- 新增业务指标：反馈总数、帮助率、验证方案数、验证方案复用次数。没有真实用户数据时保持0。
- gold-chunk回归集扩展到15题并增加3道表格专项；Hybrid相比Dense将总Recall@5从0.6000提升至1.0000。评测报告增加数据集SHA256、运行编号、检索配置和资料来源拆分；5道官方手册题的MRR@10为0.5667、nDCG@10为0.6750。
- 新增按问题类别输出的Recall/MRR/nDCG、表格抽取质量报告、索引point对账脚本和向量库选型ADR。
- 清理中断重建残留的12494个旧points，使`chunks.jsonl`与Qdrant严格一致为16969条，并在后续rebuild后自动清除陈旧points。
- 消融发现图谱扩展过宽会损害Top5召回，已改为仅在精确故障码诊断中保守扩展。

## 不能夸大的地方

- 15题仍然太少且未经过独立盲审；其中10题来自项目补充资料，官方手册题只有5道，不能称为企业级准确率。
- 经典S7-1200 V4.7尚未稳定下载入库，V4.6仍是临时保留资料。
- 当前没有真实企业工单、MTTR、一次解决率数据；业务指标需要真实使用后才有意义。
- 当前是单机本地Qdrant，不是高可用集群。
- 表格抽取目前针对有文本层和清晰线框的PDF；扫描件、跨页表和复杂合并单元格仍需OCR与人工复核。
