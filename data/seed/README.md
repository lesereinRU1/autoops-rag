# Seed data

These JSON files contain project-authored factual summaries used by the alarm, parameter, and knowledge-graph tools. They do not contain or redistribute the referenced manuals.

Each record includes a `source` or `provenance` field. Before adding a record:

1. cite the public source precisely;
2. summarize facts instead of copying substantial prose;
3. remove customer, account, device, and credential information;
4. confirm that redistribution is permitted.

See `THIRD_PARTY_NOTICES.md` for licensing boundaries.
